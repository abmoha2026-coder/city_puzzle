# city_puzzle
A procedural puzzle game where you navigate through a procedurally generated city to reach your destination while avoiding buildings.

Procedural City Generation: Each puzzle is randomly generated with buildings and roads
Adaptive Difficulty: The game adjusts difficulty based on your performance
Time Pressure: Each puzzle has a time limit that gets tighter as you progress
Pure Python: No external dependencies required
Simple Controls: WASD for movement

How to Play

1. Run the game with Python:
   ```bash
   python city\_puzzle.py


   Use the following controls:
W: Move up
A: Move left
S: Move down
D: Move right
Q: Quit the game
Navigate from your starting position (P) to the destination (D) while avoiding buildings

Game Elements
Symbol	Meaning
P	Player
D	Destination
	Building
.	Road

Difficulty Levels

The game automatically adjusts difficulty based on your performance:

Easy: Fewer buildings, more time
Medium: More buildings, moderate time
Hard: Many buildings, tight time limit
